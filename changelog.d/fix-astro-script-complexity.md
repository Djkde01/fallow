### Fixed

- **`fallow health` scores functions in Astro `<script>` blocks.** Complexity covered the frontmatter and the markup of an `.astro` file, so logic in a client script never reported. Each `<script>` block that runs as JavaScript now reports its functions at their lines in the `.astro` file: no `type` attribute, or `module`, `text/javascript`, `application/javascript` or `text/partytown`. Blocks that hold data or templates, such as JSON-LD, and blocks inside HTML comments are not scored. A project can get new findings, including CRAP findings: without coverage data, a function with cyclomatic complexity 5 reaches the default threshold of 30. The extraction cache version changes, so the first run after the update reparses all files. (Closes [#4261](https://github.com/fallow-rs/fallow/issues/4261))
